🚀 Installation & Setup

1. Clone the Repository

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY

Replace the example repository URL with your actual GitHub repository URL.

2. Install Dependencies

pip install -r requirements.txt

3. Configure Environment Variables

Set the following environment variables in your hosting dashboard:

Variable| Description
"BOT_TOKEN"| Telegram bot token
"GEMINI_API_KEY"| Google Gemini API key
"GEMINI_MODEL"| "gemini-3.5-flash-lite"

Get your Telegram bot token from "@BotFather" (https://t.me/BotFather).

Get your Gemini API key from "Google AI Studio" (https://aistudio.google.com/apikey).

Example configuration:

BOT_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash-lite

Important: Never upload real tokens or API keys to a public GitHub repository.

4. Start the Bot

If "bot.py" is the project's entry point, run:

python bot.py

☁️ Deployment on Render

1. Upload your project to GitHub.
2. Sign in to "Render" (https://render.com/).
3. Create a service connected to your GitHub repository.
4. Add the required environment variables.
5. Set the build command:

pip install -r requirements.txt

6. Set the start command:

python bot.py

7. Deploy the project and check the logs for errors.

Make sure the service type and start command match your actual project code.

🔐 Security Guidelines

- Never publish your Telegram bot token.
- Never expose your Gemini API key.
- Store sensitive credentials in environment variables.
- Rotate any credentials that have been exposed publicly.
- Avoid sharing logs containing secrets or private user information.
